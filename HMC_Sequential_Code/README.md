# Sequential Code usage

This version of the code launches a series of simulations. The files required to run this version is described below:

1. input.json: Single file. The number of elements in "k_m" array determine the number of simulations in series.
2. data.lmp: Single file. This is the starting configuration for the first simulation.
3. pair.lmp: Single file. This contains the force-field parameters for the NaCl-water system.
4. in.lmp: Single file. Contains LAMMPS settings.
5. delta_Fmn: The executable generated by compiling the sequential version of the code.

The parallel simulation is launched in the following manner:

mpirun -np ${Processors} ./delta_Fmn

The files generated by the code:
1. data.inter.lmp.${SimNo}: Intermediate data files written for each ongoing simulation. Can be used to restart the simulation.
2. data.final.lmp.${SimNo}: Final configuration at the end of each simulation written.
3. BiasInfo.${SimNo}: Crystallinity (m) and solvation State (s) bias information.
4. cls_data.${SimNo}: Binary file containing cluster size (n), crystallinity (m), and solvation state (s) data for each step in the simulation.
5. dump.${SimNo}.lammpstrj: LAMMPS format trajectory files.
6. SimulationLog.${SimNo}: Log file cluster related properties.
7. Histogram.${SimNo}: A 2D histogram data based on crystallinity (m) and solvation state (s).

Note: Please ensure that all the pre-requisite compiler modules and libraries are set correctly before running.
