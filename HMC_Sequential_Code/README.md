# Sequential Code usage

This version of the code launches a series of simulations. The files required to run this version is described below:

1. input.json: Single file. The number of elements in "k_m" array determine the number of simulations in series.
2. data.lmp: Single file. This is the starting configuration for the first simulation.
3. pair.lmp: Single file. This contains the force-field parameters for the NaCl-water system.
4. in.lmp: Single file. Contains LAMMPS settings.
5. delta_Fmn: The executable generated by compiling the sequential version of the code.

## input.json Fields

| Key | Type | Description |
|---|---|---|
| Temperature | float | Temperature of the system |
| Number of molecules | array of int | Number of Na, Number of Cl, Number of K, Number of F, Number of Water Molecules (In that sequence) |
| Number of equilibration cycles | int | Number of MC moves designated for equilibration |
| Number of production cycles | int | Number of MC moves in the production (Histogram files are written based only on this data) |
| Trajectory length | int | Number of steps in each MD run |
| Display frequency | int | Printing frequency for log file |
| Write frequency | int | Frequency to write intermediate data files |
| Dump frequency | int | Frequency to write frames to trajectory file |
| Cutoff distance | array of float | Cutoffs for finding neighbors for cluster and crystal sizes respectively  |
| timestep | float | Timestep (fs) for MD integration |
| iseed | int | random seed |
| k_m | array of float (one per simulation in series) | Constants for crystallinity bias |
| m0 | array of float (one per simulation in series) | Centres for crystallinity bias |
| k_s | array of float (one per simulation in series) | Constants for solvation bias |
| s0 | array of float (one per simulation in series) | Centres for crystallinity bias |

**Note:** The `K` and `F` atom types are dissolved Na and Cl — they have the same mass, charge, and force-field parameters as Na and Cl respectively. Adjusting the number of K/F relative to Na/Cl in "Number of molecules" is how different concentrations are set up.

The sequential simulation is launched in the following manner:

mpirun -np ${Processors} ./delta_Fmn

The files generated by the code:
1. data.inter.lmp.${SimNo}: Intermediate data files written for each ongoing simulation. Can be used to restart the simulation.
2. data.final.lmp.${SimNo}: Final configuration at the end of each simulation written.
3. BiasInfo.${SimNo}: Crystallinity (m) and solvation State (s) bias information.
4. cls_data.${SimNo}: Binary file containing cluster size (n), crystallinity (m), and solvation state (s) data for each step in the simulation.
5. dump.${SimNo}.lammpstrj: LAMMPS format trajectory files.
6. SimulationLog.${SimNo}: Log file cluster related properties.
7. Histogram.${SimNo}: A 2D histogram data based on crystallinity (m) and solvation state (s).

Note: Please ensure that all the pre-requisite compiler modules and libraries are set correctly before running.
